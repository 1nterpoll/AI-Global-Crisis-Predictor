# AI Global Crisis Predictor — Functional MVP
Live public APIs: USGS Earthquake GeoJSON feed and World Bank Indicators API v2. Dashboard, Signals, Alerts, Settings and refresh are functional. Risk score is a transparent prototype heuristic, not a validated ML forecast.

Run: npm install && npm run dev
Deploy: import this folder/repository into Vercel; framework Vite, build `npm run build`, output `dist`.
